Mention by SUGUDASU

Find it. Done. — 見つけたら、1アクションで終わらせる。

これは何か

いま開いているページを、その場で終わらせる Action Tool です。 Google口コミも、記事も、SNSも、同じエンジン（Scenario → Action → Done）です。 分析グラフも、監視も、AIチャットもありません。

  • ルールと編集可能なテンプレのみ（LLMなし）
  • 履歴は端末内の IndexedDB（クラウド保存なし）
  • データ取得はユーザー操作起点（通知・自動巡回なし）

インストール（開発者向け α）

  1. リポジトリの extensions/mention を用意する
  2. Chrome で chrome://extensions を開く
  3. 「デベロッパーモード」をオンにする
  4. 「パッケージ化されていない拡張機能を読み込む」で上記フォルダを選ぶ
  5. ツールバーのアイコンから Side Panel を開く

Chrome ウェブストア公開前の α です。Hub ナビにはまだ載せていません。詳細は extensions/mention/README.md を参照してください。

使い方（3ステップ）

  1. 口コミや記事のページを開く
  2. Side Panel の Action（返信 · Slack共有 など）を押す
  3. 定型をコピーして貼る → 完了

やらないこと

感情分析・レポート・監視アラート・担当者管理・LLMによる文章生成は作りません。
