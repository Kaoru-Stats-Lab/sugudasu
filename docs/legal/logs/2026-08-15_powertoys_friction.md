## この会議で決めたこと

PowerToysの機能セットを移植しない。OS常駐・ランチャー・設定・OCR・AIペーストで新規HTMLを足さない。

有効なJTBDは **既存ツールの入口/出口** へ翻訳する。

**新規ツール 0 の範囲:** 本件（PowerToys監査）の結論である。SUGUDASU が今後一切新規HTMLを出さない、という意味ではない。外向けに「機能を増やさない」と宣言しない（約束が負債になる）。

SUGUDASUが解く摩擦は次の3つに限る。

1. **形式の非互換**（Excel / Word / メール / HTML のねじれ）
2. **視認と確認の中断**（別アプリを開いて閉じる）
3. **単純反復の摩耗**（同じ規則を手で何回も）

仮置きの定義は CASE-2026-010 を維持する。乗降プラットフォーム（Transit Handoff）という言い方は卓上と同義。保管庫にしない。

形式変換のロジックは仮置きに増やさない。表の形式出口は既に `table-conv`。Normalize は **1つのテキストを貼り先向けに整える** 道具であり、多数対象への一括改名（PowerRename）をトグルで足さない。

## ステータス語彙（一段。HOLD≠着手可）

| 語 | 意味 | 製品コード |
|----|------|------------|
| **Keep** | 出荷済。再審しない | 触らない |
| **Reject** | 不採用 | 入れない |
| **着手不可** | 今期の製品に入れない。再開条件が閉じるまでチケット不可 | 入れない（検証プロトタイプも製品ブランチ禁止） |
| **PARK（範囲付き）** | 先送り。対象スコープと再開トリガー必須。トリガー前は塩漬けに見えるが、トリガー無しの PARK は禁止 | トリガーまで入れない |

旧ログの HOLD と「今すぐ足さない」の二重表記は廃止する。HOLD を着手可と読んではならない。

## 仮置きに入れないもの（根拠）

| 提案 | 判定 | 根拠 |
|------|------|------|
| カードフッターに TSV / Markdown / HTML コピーを常時出す | Reject | コピーが最短導線。95% の「そのまま」にヒックの法則のノイズを常時課す。変換は少数派で `table-conv` へ |
| テキスト/表の Space を全画面にする | 着手不可 | P0-B は識別強化を画像/PDFに限る（中身が視覚的に不透明）。非対称は意図。UT で誤読を一度見る |
| 画像カード上の矩形クロップ → 新カード複製 | 着手不可 | 「編集しない」。部分コピーに見えるかはプロトタイプで聞く |
| セッション終了で自動破棄 | Reject | IndexedDB 永続が現行。消滅不安があると卓上に置けない（`copipe-taihijo`） |

## 観測だけ（機能を足さない）

破棄 UI ・容量バー ・期限表示は足さない。  
何も消えない状態が続くと、利用行動の側から保管庫化する。週次は既存の仮置き開封・着手・完了率だけを見る。カード枚数は計測イベントに載せない（本文・ペイロード統計禁止）。
