# SUGUDASU Graph — 軸ラベル向き・出典（Excel機能の採否）

**Date:** 2026-08-14  
**Question:** Excel の「軸の書式設定→文字列の方向」と「挿入→テキストボックスで出典」を SUGUDASU につけるか  
**Verdict:** **どちらも Excel 同等UIはつけない（REJECT）。** 必要なら別の最小手段だけ。

関連: [`PRESENTATION_OUTPUT_CONSTITUTION.md`](./PRESENTATION_OUTPUT_CONSTITUTION.md) POC-004/006 · 貼付後編集不可 · Editor 禁止

---

## 一行裁定

| Excel機能 | 採否 | 代わり |
|-----------|------|--------|
| 軸の書式設定で文字列の方向を縦書き等に変更 | **REJECT**（書式パネルUI） | **Renderer が自動**（長いラベル→斜め／必要なら縦）。任意なら後で向きプリセット2〜3個まで |
| テキストボックスで出典をグラフに追記 | **REJECT**（自由配置テキスト＝Editor） | **出典はデッキ側に書く**（憲法どおり）。任意1行 `source` フィールドは HOLD（今は必須にしない） |

---

## 1. 文字列の向き

### つけないもの

- 右クリック「軸の書式設定」
- 配置・縦書き・回転の自由ダイヤル
- 軸オブジェクトを選んでハンドル操作

→ Graph Editor 化。貼付後編集不可なら、そのUIを SUGUDASU 内に再現する動機も弱い（一発出力が本命）。

### つけるもの（デフォルト品質）

| 挙動 | 判定 |
|------|------|
| ラベルが長いとき **自動で斜め or 縦** にして切れない | **GO**（Acceptance / 余白問題と同列） |
| 半面スロットでは最初から縦寄り | **GO**（スロット連動） |
| Settings で `label_orient: auto \| angled \| vertical` 程度 | **GO-AFTER**（色ロールの後でよい） |

ユーザー作業は「向きをいじる」ではなく「読めるグラフが出る」。

---

## 2. 出典名

### つけないもの

- 挿入 → テキストボックス
- グラフ上の自由ドラッグ文言
- 複数注釈・吹き出し

POC-004: **出典は SVG に原則含めない**（タイトル・長文注釈と同列）。デッキ（PPT/Slides/Impress）に書くのが一次。

### 許容候補（今は HOLD）

| 案 | 判定 |
|----|------|
| Presentation Settings の **出典1行**（図の外・下マージンに小さく） | HOLD — 需要が固まったら別ジャッジ。自由配置ではない |
| 出典を必須入力にする | REJECT — 3分・貼る作業を増やす |

IR 資料でも出典はスライドのキャプション／脚注で足りることが多い。

---

## 既存ロックとの整合

| ロック | 効き方 |
|--------|--------|
| Editor 禁止 | 書式設定パネル・テキストボックスは典型的 Editor |
| 貼付後 SVG 編集不可 | デッキで直す前提にしない。向きは出力時に正しく |
| POC-004 | 出典・タイトルは原則デッキ |
| 色ロール MUST | 色は Settings。軸向きの自由編集は同列にしない |

---

## Cursor への実装指示

- **今実装するな:** 軸の書式設定UI、テキストボックスUI  
- **やってよい:** 長ラベルの自動向き（切れ防止）を Renderer デフォルト改善として検討  
- **やるな:** 出典必須フィールドを急に足す  

---

## まとめ

> Excel の「書式で直す」「テキストボックスで足す」は **つけない**。  
> SUGUDASU は **最初から読める向きで出し、出典は資料側に書く**。
