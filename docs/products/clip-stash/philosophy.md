# SUGUDASU 仮置き — 思想 · Non-Goals

**正本:** 本ファイル（Non-Goals）· `specification.md`（操作・実装）· `SPEC_HANDOFF.md`（出口の HOW）  
**更新:** 2026-08-15

---

## このツールは何か

仕事中に発生した一時情報を、思考を止めずに手元へ広げ、次の場所へ渡す。

PureRef でも、メモアプリでも、ノートでも、クリップボード管理でも、**知識管理ツールでもない**。Edge Drop の簡易版でもない。

**作業中の素材を、次の場所へ渡すための卓上**である。

```
コピー → 仮置き → 使う → 終わる
```

ここに保存 · 分類 · 検索 · 再利用を足したら別プロダクトになる。

コピーしたものを自由に並べておく。整理しない。編集しない。仕事が終われば消えていい。

保存ではないが、置いたデータを勝手に加工する場所でもない。

---

## なぜ Non-Goals があるのか

SUGUDASU 仮置きは、**情報を管理するためのツールではない**。

一時的に置き、必要になったら戻し（コピーまたは出口 DnD）、仕事へ戻るための道具である。

**管理を始める機能は、このプロダクトの存在理由そのものを変えてしまう。**

そのため、以下は意図的に実装しない。

これらは「便利だから」ではなく、**管理行為そのものを生み出すため**採用しない。

この一覧は「今は作らない機能」ではない。  
**ブランド憲法により、意図的に採用しない機能**である。

---

## 判断に迷ったら

新しい機能案が出たときは、最初に問う。

> **それは仮置きを管理する機能か、次へ渡す／確認するための機能か**

| 判定 | 扱い |
|------|------|
| 管理するため（整理 · 保管 · 検索 · 同期） | **Reject** |
| 次へ渡すため（コピー · 出口 DnD） | 検討対象 |
| 置いたものを確認するため（Preview） | 検討対象 |

保存は「あとで取り出す」。仮置きは「今、次へ渡す」。

## Non-Goals — 実装しないもの

機能追加の可否は、まず上記の問いとこの一覧に立ち返る。

| カテゴリ | 実装しない |
|----------|------------|
| 整理 | タグ · フォルダ · ラベル · ピン留め · お気に入り · 種類フィルタ · 名前付け |
| グループ | 手動グループ化 · 画像スタック · グループ名 |
| ノート化 | ノート · コメント · 履歴 · バージョン管理 |
| 探索 | 検索 · フィルター · OCR検索 |
| 見た目の意味付け | 色分け |
| 自動化 | スマート配置 · 自動整列 · AI分類 |
| 常駐 UI | 画面端ホットエッジ · 隠れた専用パネル |
| 設定 | 起動時動作 · 表示位置 · モニタ選択 · 文字サイズなどの細かいカスタマイズ |
| 通信 | 端末間同期 · 「自分への送信」（Sync レーン。コア仮置きではない） |

上記は「便利だから」追加しない。仮置きは **並べて、確認して、渡す** · **コピーが最短導線** を最後まで守る。

複数カードの選択 · 一括削除 · 一括出口は「整理」ではなく作業操作である。グループ管理とは別物（CASE-2026-010）。

## 憲法との関係

- **Brand Constitution:** 考えない · 教えない · 整理しない · 提案しない
- **Product Constitution:** 処理ゼロの滞留装置。F5（3分加工）型のツールとは別種
- **Anti Principles:** PureRef化 · ノート化 · 高機能化 · AI化 — すべて Reject 方向
- **カテゴリ期待（C-10）:** クリップボード管理 · Edge Drop 一式 · PowerToys 一式は移植しない
- **形式変換:** 仮置きに形式ボタンを増やさない。表の出口は `table-conv`。Normalize に多数ファイルの一括改名を載せない（CASE-2026-011）

詳細な操作拒否リストは `specification.md` を参照。出口の実装は `SPEC_HANDOFF.md`。
