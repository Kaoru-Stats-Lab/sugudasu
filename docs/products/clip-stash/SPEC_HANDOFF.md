# SUGUDASU 仮置き — 出口（Handoff）実装仕様

**id:** `clip-stash`  
**更新:** 2026-08-15  
**状態:** 実装済（P0-B · P0-A · P0-C · P1）  
**憲法:** [CASE-2026-010](../../legal/CASE_LAW.md#case-2026-010)  
**製品正本:** [`specification.md`](./specification.md)（本ファイルは HOW · 受け入れ条件）  
**思想:** [`philosophy.md`](./philosophy.md)

仮置きは Edge Drop の簡易版ではない。**作業中の素材を次の場所へ渡す卓上**である。

```
外部  →  仮置き  →  外部
置く         確認する         持っていく
```

保存（あとで取り出す）ではない。仮置き（今、次へ渡す）である。  
**保存ではないが、置いたデータを勝手に加工する場所でもない。**

カードは持ち出しても残る（コピー。切り取りではない）。

---

## Handoff Principles

1. **置いたものを変質させない。**
2. **仮置きから外へ持ち出せる。**
3. **持ち出しても仮置き側には残る。**
4. **外部 DnD はベストエフォート。Web が保証できないことを製品保証にしない。**

成功を保証するのではなく、**成功した場合のデータ品質を保証する。**

「置いたものを確認できる」→「確認したものを次へ渡せる」。この順は変えない。

## データ品質（出口でも Preview でも）

仮置きは、置いたファイルを変質させない。

```
ローカル画像 / PDF
  → 仮置き
  → プレビュー（表示キャッシュは別。本体は触らない）
  → 外へ DnD またはコピー
  → 元ファイル相当
```

禁止:

- PNG → JPEG 化しない
- PDF → PNG 化して渡さない（ボードサムネ PNG は表示専用。出口・コピーの本体は PDF）
- 解像度を落とさない
- EXIF 等を勝手に除去しない
- MIME を勝手に変更しない
- Canvas 再エンコードしない（ADR-CS-002）

外部へ渡せたとき、渡ったバイト列は置いたときの本体と同一であること。渡せなかったときは、この品質義務は発生しない（原則 4）。

## P0-A — 出口 DnD

### 目的

ダブルクリック（クリップボードへ戻す）に加え、カードを **他アプリ / デスクトップ / エクスプローラーへドラッグして渡す**。

例（意図。OS が受け取る範囲は後述の制約に従う）:

- 画像 → PowerPoint / Word
- PDF → デスクトップ / エクスプローラー
- テキスト · 表 · URL · 色 → フォーカス中のテキスト欄

同一ドラッグ。専用ハンドルもモードもない。「並び替えモード」「エクスポートモード」をユーザーに考えさせない。**持っていく**だけ。

| ドロップ先 | 動作 |
|------------|------|
| ボード上のスロット | **並び替え**（現行） |
| SUGUDASU ウィンドウの外（他アプリ · デスクトップ） | **出口**（コピーとして渡す · カードは残す） |

`effectAllowed = 'copyMove'`。ボード上は `move`、外は `copy`。

未選択カードは現行どおりドラッグ不可（P1 で複数選択時は、ドラッグ開始カードが選択集合に含まれていれば集合を出す）。

### ペイロード（P0 必須）

現行 `dragstart` は `text/plain` に **カード UUID** を載せている。出口を足すと他アプリへ UUID が落ちる。禁止。P0 必須テスト。

| MIME | 用途 |
|------|------|
| `application/x-sugudasu-clip-stash` | 内部のみ。JSON `{ ids: string[] }`。ボード drop はこれだけ見る |
| `text/plain` | ユーザー向け本文。text / table(TSV) / url / color。image·pdf はファイル名のみ（**UUID を書かない**） |
| `text/html` | table のみ任意（単純な `<table>`。スタイリングしない） |
| `text/uri-list` | url カード |
| `DownloadURL` | Chromium 系の**実装手段の一つ**。image / pdf をファイルとして渡す試み。Web 標準の保証ではない |
| `Files` / `items.add(File)` | 可能なら image / pdf の File。変質させない |

内部 MIME が読めない drop はボード並び替えに使わない。

ファイル名は表示用の短い名前でよい（`image.png` · `document.pdf`）。ユーザーに付けさせない（名前付け Reject）。

`DownloadURL` は「デスクトップにファイルを DnD できること」を製品として約束する語ではない。対応環境でファイルとして渡せた場合に、上記データ品質を満たすために使う。

### 出口のあと

- カードは削除しない
- 成功トーストや「PowerPoint に送りました」は出さない（チャネル名付き案内は CASE-2026-007）
- 失敗ダイアログ · 失敗トーストも出さない。OS が受け取らなければ何も起きない
- **フォールバックは既存のコピー。** 外部 DnD が成立しない環境でも、ダブルクリック（および Preview 中のコピー）で常に出せる。これが壊れないことが受け入れ条件
- `SG_ANALYTICS.notifyJobDone` は、ブラウザが `dropEffect !== 'none'` を返せるときに限り `copy` 相当。取れなければ計測しない

### ブラウザ制約（約束してよい範囲）

HTML5 のページ外 DnD は OS · ブラウザ依存。ネイティブアプリ化・拡張・権限追加で埋めない。

| 経路 | Chromium（Windows） | Firefox / Safari |
|------|---------------------|------------------|
| テキストをテキスト欄へ | やる | やる |
| image / pdf をデスクトップ · エクスプローラーへ | 対応環境ではファイルとして渡す**試み**（`DownloadURL` 等）。受け取れなくても欠陥にしない | 同左 |
| image を PowerPoint / Word へ | ベストエフォート。失敗してもコピー導線が残れば足りる | 同左 |
| 複数ファイルを一度に OS へ | P1。1件だけ渡っても P1 合格可 | 同左 |

Edge Drop の Win+Shift+S 貼り付け不具合は **OS クリップボードの話**。仮置きは元バイトを保持し、出口では本体 File を載せる試みをする。DIB 修復やスクリーンショット専用分岐は作らない。

### 実装メモ

- `copyCard` と出口ペイロード生成を分ける。出口は `dragstart` 同期制約があるので、**ドラッグ開始前に Blob/File を用意できるカードだけ** File を載せる（IndexedDB の ArrayBuffer は既にメモリ上の `cards` にある）
- 並び替え drop ハンドラは内部 MIME 優先。`text/plain` の UUID フォールバックは削除する
- テストはペイロード組み立てを `clip-stash-engine.js` に純関数として置き、`clip-stash-engine.test.mjs` で **UUID 漏洩禁止**と種類別 MIME・**元バイト同一**を固定する

## P0-C — 置ける場所の明示 · 持ち出し視覚

チュートリアル文 · 新規ヒントテキストは足さない。「エクスポート」という UI 表現も出さない。

| 状態 | UI |
|------|----|
| 常時 | Input Strip「ここへ貼り付け・ドラッグ」を **カードが増えても残す**（現行 Keep） |
| ドラッグ開始 | カードが少し浮く（現行 `is-dragging` で足りれば流用） |
| ボード上をドラッグ中 | 現行のスロットハイライト · 入れ替えスライド。**並び替え候補**が見える |
| ポインタがボード外（ウィンドウ内） | スロットハイライトを消す。カードゴーストは残す。**持ち出している**ことが身体感覚で分かる。候補: `body.is-cs-drag-exit` でボードを少し沈める。説明文は出さない |
| ウィンドウ外 | OS カーソルに委譲 |

「ここにファイルを置けます」という **入口を、カード一覧の裏に隠さない**。

「ボードを少し沈める」だけで出口が分かるかは **実装時に実機確認**する（P1）。足りなければゴーストの浮きを強める。ラベルやトーストで補わない。

## P0-B — 画像 / PDF の識別プレビュー

### 目的

置いたものが何かを、Space 一発で識別する。編集・独自ズーム・ギャラリー巡回はしない。

合格条件は iframe やパネルの CSS サイズではない。**ファイル識別性**である。

横方向の見切れは、ファイルの一意性を確認する手段としてのプレビューの敗北である。

### 現状との差

現行プレビューパネルは `width: min(42rem, 92vw)` · `max-height: min(80vh, 36rem)`。画像は `max-height: min(60vh, 28rem)`。識別には狭い。

### 仕様

| カード | パネル | 本体 |
|--------|--------|------|
| image | ビューポートの大部分（目安: 幅 `min(96vw, 90rem)` · 高さ `min(92vh)`） | `object-fit: contain`。画像全体が切れずに見える。メタ行（形式·寸法·容量）は残してよい |
| pdf | ビューポートの大部分（手段） | ADR-CS-003 維持。iframe 委譲 · pdf.js で Space を描かない。**合格は「PDF 本文の横方向が見切れず、少なくとも 1 ページの識別に必要な横幅がある」** |
| text / table / url / color | **現行サイズのまま** | 巨大化しない |

PDF の入れ子（SUGUDASU modal → iframe → ブラウザ PDF Viewer の toolbar / sidebar / viewport）を忘れるな。iframe を `96vw` にしても、Viewer 側の chrome とズームで本文は見切れる。`#toolbar=0&navpanes=0&view=FitH` は現行どおり試みるが、URL パラメータが効かないブラウザでは効かない。自前 pdf.js 描画や独自ズーム UI で埋めない。ページ送り UI を自前実装しない。

共通:

- 独自ズーム UI 禁止。拡大は OS / ブラウザのページズームに委譲
- 隣接カードへの次へ/前へ禁止
- ダブルクリックまたは既存どおりコピーで閉じる
- 背景暗転 · Esc で閉じるは維持

## P1 — 複数選択（グループ化ではない）

### やってよいこと

- **Ctrl+Click**（macOS は `metaKey`）で選択トグル
- 選択中の視覚（現行の選択リングを複数枚に）
- **Delete** で選択集合を一括削除（空スロットは現行どおり残す）
- 選択集合に含まれるカードをドラッグ → **一括出口 DnD**（P0-A のペイロードを複数 `ids`）
- P0-C の持ち出し視覚を実機で確認し、沈めるだけでは足りなければゴーストを強める（コピーは足さない）

### やらないこと

- 名前付きグループ · フォルダ · スタック
- 画像同士をドロップして結合
- フィルタ（IMAGE / URL / TABLE / TEXT）
- Shift+Click 範囲選択（表計算の選択感。P1 対象外）
- 投げ縄 / 矩形選択
- Ctrl+A 全選択（机を管理する操作に見える。必要なら後で再審）
- 複数カードのブロック並び替え（ドロップ先がボードなら **並び替えしない**。誤ドロップで机が崩れない）
- 「エクスポート」ラベル

クリック（修飾キーなし）は単一選択に戻す（現行）。

## コピー（実装時に直す）

製品コピーは実装と同時。slug を出さない。

- リード: 「置く」だけでなく「次へ渡す」が1文で分かること。How（キー一覧）はリードに書かない
- Empty: 「整理しない。編集しない。仕事が終われば消えていい。」は維持してよい
- FAQ: ダブルクリックに加え、カードを外へドラッグして渡せる旨。PowerPoint 等のチャネル名を CTA にしない。外部 DnD が環境によって届かないことは、ユーザー向けに「保証します」と書かない
- `data-sg-subtitle`: 出口が載ったら「貼り付け · ドラッグ · ダブルクリックでコピー」を「置く · 確認する · 持っていく」系へ検討

## 受け入れ条件

### P0-B

1. Space で画像が、現行より明らかに大きく、切れずに contain 表示される
2. Space で **PDF 本文の横方向が見切れず、少なくとも 1 ページを識別できる**（iframe が大きくなっただけでは不合格）
3. テキストカードのプレビューサイズは現行から大きく変えない
4. ズームボタン · 次へ/前へが無い
5. PDF 本体を PNG に変えて渡す導線が無い（表示キャッシュはボード用のまま）

### P0-A / P0-C

1. ボード上ドロップで並び替えが現行どおり動く
2. **`text/plain` にカード UUID が乗らない**（必須テスト）
3. テキストカードをメモ帳等のテキスト欄へドロップすると本文が入る（Chromium）
4. Chromium / Windows の標準環境で、image / PDF の外部ファイル DnD が**可能なケースでは、元バイトを保持したファイルとして渡せる**。受け取れない環境・アプリは欠陥にしない
5. 出口のあとカードが消えない
6. Input Strip がカード 1 枚以上でも残る
7. 成功・失敗いずれの新規トーストも無い
8. **外部 DnD が成立しない環境でも、ダブルクリック / Preview コピーによる既存の出口が常に使える**
9. ドラッグ中、ボード内（並び替え）とボード外（持ち出し）が視覚的に区別できる。「エクスポート」文言は出ない
10. エンジンテストが UUID 漏洩と、ファイルペイロードがある場合の**元バイト同一**を固定する

### P1

1. Ctrl+Click で 2 枚以上選べる
2. Delete で選んだカードだけ消える
3. 選択集合のドラッグをボード上でドロップしても並びが壊れない（no-op）
4. グループ名・結合 UI が無い
5. 持ち出し視覚が、沈めるだけでは足りない場合にゴースト強化で解消されている（文言で補っていない）

### 全優先度共通

- サーバー送信なし · Sync なし · 設定画面なし
- 置いた image / PDF を再エンコード · MIME 変更 · 解像度低下しない
