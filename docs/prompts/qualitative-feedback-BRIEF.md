## プロダクト（事実）

SUGUDASU は **登録不要・ブラウザ完結** の実務ツール群。仕事中に一瞬使い、結果を **コピー／PDF／印刷** で持ち帰り、すぐ元の仕事（Excel・メール・チャット）へ戻る。  
**Identity（アカウント）が無い。** 利用計測は GA4 の行動イベント（開封→着手→完了）があるが、**「なぜ困ったか／何が助かったか」の定性は取れない。**

### いまの仮説（役員会暫定 · 最終ではない）

| 項目 | 暫定 |
|------|------|
| 目的 | FB を **受けやすくする受け皿**を先に作る（件数は現時点では少なくてよい） |
| 公開星・レビュー・ランキング | **Reject**（Hub Non Goal · エンゲージメント文化） |
| Google Form 等への **外部遷移** | **Reject寄り**（ユーザーは戻ってこない／書かない） |
| FAQレビュー＝定性取得 | **Reject**（目的不一致） |
| 通信が要る送信 | **別枠ポリシー**（仕事データ非送信は維持 · FBメタのみ） |
| GA4 vs 定性 | 置換しない。行動は地図、定性は理由 |
| 完了直後（コピー成功時） | ユーザーは **SUGUDASU に留まらない可能性が高い** → 「終わった瞬間だけ」に依存しない設置も要検討 |

### 憲法・Anti（要約 · 正本はリポ）

- Persona: 前に出て教え込まない同僚 · 終わったら静かに去る  
- Anti: 囲い込まない · 提案しすぎない · UIで目立たない · 登録を目的化しない  
- F2/Commentary: ユーザー入力・成果物・業務データの非送信。**任意の短い製品FBメタ**は別議論（Core静的＋明示オプトイン送信 / Sync枠）  
- Hub: 星評価・利用数・公開レビューは Non Goal  

正本ポインタ: `ANTI_PRINCIPLES` · `HUB_CONSTITUTION_SPEC` §14 · `PRODUCT_USAGE_ANALYTICS` · `DATA_PRIVACY_CLAIM_POLICY`（該当時）

| してよい | してはいけない |
|----------|----------------|
