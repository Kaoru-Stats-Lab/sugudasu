## 1.5 どこで使うか · 場所で変えるか · 英語か（2026-08-13）

### 結論（役員会たたき台）

1. **キャッチは1本の「世界観コア」＋場所用の「事実サブロウ」に分ける。** 同じ英文を全面に貼らない。  
2. **いまの本番主戦場は日本語。** 英語タグラインは「国際向け・ブランド記号」として使えるが、**日本語LPのヒーロー本文の代替にはしない**（現状 Hub は「登録不要・ブラウザ完結」系が正）。  
3. **ローカライズは逐語訳ではなく、同じ三拍子の再執筆。** `Open. Use. Close.` は構造が移植しやすい。`Browser. Nothing Else.` は言語ごとに語感が変わる。

### 置き場所マップ（現状リポに存在する面）

| 面 | 現状の例 | 世界観コア（英）向き？ | 何を置くべきか |
|----|----------|------------------------|----------------|
| **Hub ヒーロー** | 「ブラウザだけで完結。登録不要。」 | △ 英だけは弱い | **日本語の世界観**（Open. Use. Close. の意訳）＋短い事実 |
| **meta / OGP / Twitter** | 「登録不要・無料…」「会員登録ゼロ、データ非送信」 | × 検索・共有は母語 | **日本語事実**（登録不要 · ブラウザ完結）。英コアは任意の副題級 |
| **ツールページ LP** | JTBD · ツール固有 | × | ツールの Pain。ブランドコアは小さく（フッター/約束リンク） |
| **Hub カード blurb** | JTBD 2文 | × | ブランドキャッチ禁止（カード指南） |
| **statements / 約束** | 原則の説明 | △ | 世界観の**解説**は可。キャッチ単体の連打は不要 |
| **X / Zenn / PR** | 記事・投稿 | ○ | 英コアを記号として使える。本文は日本語 |
| **ファビコン隣・スプラッシュ・将来 en.** | （薄い） | ◎ | 英コアの本命置き場 |

### 場所で変えるか

| 層 | 役割 | 例 |
|----|------|-----|
| **L0 コア（ブランド記号）** | 言語を超えて同じリズム | `Open. Use. Close.` |
| **L1 面の母語ヒーロー** | その面の言語で世界観 | 開く。使う。閉じる。 / Just open — just done. |
| **L2 事実行** | 誤解防止 · SEO · 法的に安全な説明 | 登録不要 · 業務データはサーバーに保存しない（C-05） |
| **L3 ツールJTBD** | その道具の仕事 | 「手取りから領収書を…」 |

**同じ L0 を L2 の代わりにしない。** `No Login. No Upload.` は L2 寄り。今回の本線案は **L0/L1**。

### そもそも英語か

| 論点 | 判断 |
|------|------|
| 今すぐ全サイト英字ヒーローにするか | **No** — ユーザーは日本語実務。既存 Hub/OGP は日本語が正 |
| 英コピーを持つか | **Yes（候補として）** — 短い・記憶・海外向け・デザイン上の記号 |
| 日本語と併記するか | Hub なら「開く。使う。閉じる。」主、英は小さく、が安全 |
| 英だけが通じるか | 日本の事務ペルソナには **L2 日本語がないと不安**（登録不要が読めない） |

### ローカライズしたとき使えるか

| 案 | 移植性 | メモ |
|----|--------|------|
| **Open. Use. Close.** | **高** | 三動詞。JA「開く。使う。閉じる。」EN そのまま。他言語も動詞3つで再執筆可 |
| **Just Open. Just Done.** | 中〜高 | Just の韻は英語依存。JAは「開いて、終わる。」で別リズム |
| **Browser. Nothing Else.** | 中 | Browser は借用語でJAでも可。他言語は「ブラウザ／何もいらない」再執筆 |
| No X. No Y. 系 | 中 | 否定並列は多言語で強いが、Send/Cloud は法・Sync で注釈が要る |
| Zero Trace / No Exit 系 | 低〜危険 | 誇張・暗喩が翻訳で悪化しやすい |

**原則:** L0 は「訳す」より **同じ構造で各国語を書く**。辞書訳の `Open. Use. Close.` → 不自然な直訳はしない。

### 1.6 英語 Native 監査 — Open. Use. Close.（2026-08-13）

**問い:** 日本人には伝わるが、英語 Native には違和感／Japlish に見えないか。コンセプトは伝わるか。

#### 結論

| 項目 | 判定 |
|------|------|
| Japlish / 文法破綻か | **否** — テレグラフィックなブランド英語（Just Do It 型）。冠詞省略はタグラインでは普通 |
| コンセプトは伝わるか | **伝わる（セッション寿命）** — 開く → 使う → 閉じる＝滞在しない道具 |
| F1/F2（登録不要・非送信）まで伝わるか | **伝わらない** — それは L2 の仕事。L0 に求めない |
| Native が感じる弱さ | 中段 **Use** がやや汎用。致命傷ではない |
| 本番 en 面でそのまま使えるか | **Yes（L0として）** — 下に一文の L2 を添える運用が安全 |

#### Native が自然に読み取る意味

1. 短いセッション（open something → use it → close it）  
2. インストールやオンボーディングの物語ではない  
3. 「ここに居続けろ」系 SaaS の反対

SUGUDASU の存在様式（必要な瞬間だけ使い、持ち帰り、元の仕事へ戻る）と **方向は一致**。

#### 違和感になりうる点（許容範囲）

| 点 | 深刻度 | 扱い |
|----|--------|------|
| **Use** が弱い・曖昧 | 低〜中 | タグラインではよくある。Work/Finish に変えると韻が崩れるので **Keep Use** |
| **Close**＝タブを閉じる／仕事を終える | 低 | Open と並ぶとブラウザ文脈で十分。Close the deal とは読まれにくい |
| 三語命令のトーンがそっけない | 低 | Persona（前に出ない同僚）と整合。温かみは L1/L2 で足す |
| 登録不要・非送信が言えていない | — | **仕様**。L0≠L2。英 en 面でも "No account. Data stays in your browser." 等を併記 |

#### Japlish になりやすい例との対比（参考）

- 危険例: 意味不明な抽象語の羅列、存在しないイディオム、過剰な "Let's enjoy …"  
- **Open. Use. Close.** はそれに当たらない。既存の英語セットフレーズとの衝突もない（No Leave / No Exit より安全）

#### 推奨併記（en 面・海外向け1枚）

```text
Open. Use. Close.
No account. Your work stays in the browser.
```

（Send/Upload の絶対語は C-05 どおり注釈可能な言い回しを選ぶ）

### 1.7 比較 — Open. Work. Close.（2026-08-13）

**問い:** 中段を Use → **Work** にした方がよいか（Use が弱い、への対案）。

| 観点 | Open. **Use.** Close. | Open. **Work.** Close. |
|------|------------------------|-------------------------|
| Native の響き | 道具を使う。そっけないが自然 | より力が強い。生産性コピーに近い |
| Japlish | なし | なし |
| セッション寿命 | 伝わる | 伝わる（むしろ「仕事して終わる」） |
| **Domain（憲法）** | **◎ 道具を使う** — SUGUDASUは仕事そのものではない | **△ 摩擦** — 中段が「ここで仕事する」に読める |
| Mission | 仕事へ戻す前工程 | 「Work」が本丸の仕事に聞こえると Domain とズレ |
| Persona | 隣の同僚が道具を渡す | ワークスペース／労働の場に寄る |
| CMO | やや弱い中段 | パンチがある · SaaS「Get work done」族に近づくリスク |
| 日本語 L1 | 開く。使う。閉じる。 | 開く。**働く。**／**仕事する。** — 「働く」は違和、作業するは長い |

#### 役員会風の一文

- **Work** は英語としては Use より強く、違和感も少ない。  
- ただし憲法 Domain は「仕事そのものではない」。中段 **Work** は **仕事の場に聞こえる**リスクがあり、**Use（道具）の方が条文と一致**する。  
- よって **L0 は Use のまま**が憲法整合。Work は「よりマーケ強い姉妹案」としてストック（採用するなら Domain 注釈か「短い実務を片付ける」読みを L1 で固定）。

| 案 | 扱い |
|----|------|
| **Open. Use. Close.** | **L0 確定**（2026-08-13 · 提督再確認「USEで進める」） |
| **Open. Work. Close.** | 不採用（姉妹検討済 · Domain 摩擦で見送り） |
